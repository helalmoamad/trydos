# Profile Page Requirements

1. Add a profile page design.
2. The user can change the app language from the profile page.
3. The user can log out from the profile page.
4. When the user taps on User Information, the app should navigate to an information page where the user can:
   - Share their QR code.
   - View their name and phone number.
   - Add a new phone number in the future.
   - For now, this page is design only.
5. From the profile page, when the user taps on their profile image, the app should navigate to the image management page where the user can add, edit, and delete profile pictures.
6. Images can be added from either the gallery or the camera.
7. After selecting an image, the user can crop it.
8. Once an image is selected, a Save button should appear in the top bar, and the user must press it to save the image.
9. If the user's account is not verified, they can verify it by tapping the Protect Now button on the profile page.

## Note

The account verification flow is not fully implemented yet.
